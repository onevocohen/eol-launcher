# EOL Kickoff Toolkit

Read and follow the repository-root [SKILL.md](../../../SKILL.md) as the authoritative workflow. It contains the questions to ask, the Asana lookup and duplicate-prevention rules, and the procedures for creating the deck, calendar invite, and Slack channel.

The workflow scripts are in the repository-root `scripts/` directory. Resolve `SKILL_DIR` to the directory containing the repository-root `SKILL.md` before running them. Do not run workflow scripts as tests; they call live external services.
